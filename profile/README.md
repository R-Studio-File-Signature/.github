## Starting with R-Studio

Prerequisites: Authorized access to the source media, a separate healthy destination disk, and enough unused space to store recovered files.

1. **Prepare:** Stop writing to the failing disk and confirm destination storage before opening R-Studio.
2. **Configure:** Launch R-Studio, select the disk or enable R-Studio network recovery mode for an authorized remote target.
3. **Scan:** Run the R-Studio data recovery scanner and, when needed, R-Studio file signature search for known types.
4. **Reconstruct:** Use R-Studio RAID reconstruction tools if array parameters must be rebuilt carefully.
5. **Copy Out:** Preview found items, then save recovered data only to healthy storage outside the source disk.
6. **Repeat:** Document results and rescan only when new evidence appears, keeping the R-Studio overview accurate over time.
